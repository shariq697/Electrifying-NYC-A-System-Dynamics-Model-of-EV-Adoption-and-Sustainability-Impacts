⚡ Electrifying NYC: System Dynamics Model of EV Adoption

This project is a system dynamics model built in InsightMaker that simulates the transition from internal combustion engine vehicles (ICEVs) to electric vehicles (EVs) in New York City. It analyzes the environmental, economic, and resource impacts of large-scale EV adoption.

The model incorporates delays, feedback loops, and variability to reflect real-world adoption patterns and infrastructure constraints.

🎯 Objective

To evaluate how EV adoption impacts:
- Carbon emissions reduction  
- Energy demand  
- Economic costs and benefits  
- Resource requirements for urban transportation systems  

🧠 Key Components

- EV adoption rate modeling  
- ICE vehicle decline simulation  
- Emissions comparison (ICE vs EV)  
- Infrastructure demand considerations  
- Policy and sustainability feedback loops  

📊 Insights Generated

- Long-term reduction in greenhouse gas emissions  
- Transition dynamics between ICEVs and EVs  
- Impact of adoption speed on sustainability outcomes  
- Resource and infrastructure implications for urban planning  

🛠️ Tools Used

- InsightMaker (System Dynamics Modeling)  
- Conceptual systems modeling techniques  
- Scenario-based simulation analysis  

⭐ About This Project

This project explores sustainable transportation systems by modeling the transition to electric vehicles in urban environments. It demonstrates system thinking, simulation modeling, and policy analysis for real-world environmental challenges.
